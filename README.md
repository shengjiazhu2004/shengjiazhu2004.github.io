# Shengjia Zhu — Personal Website

This is a build-free static website prepared for GitHub Pages.

## Local preview

From this directory, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

1. Replace the `SZ` portrait placeholder in `index.html` with a real profile image if desired.
2. Check the contact links, research descriptions, and dates.
3. Keep `index.html`, `styles.css`, `.nojekyll`, and `assets/` at the repository root.

## Publish with GitHub Pages

For the GitHub account `Itareso`, create a public repository named `itareso.github.io` and push this directory to its `main` branch. In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.

The website will be available at `https://itareso.github.io/` after GitHub finishes deployment.
